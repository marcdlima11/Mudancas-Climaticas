# Título do Ebook : Desafios das Mudanças Climáticas no Brasil para 2025 e Como Minimizar seus
Efeitos ;)

## 📒 Descrição
Ebook criado por IA. Foi utilizado CHAGPT para a estruturação dos temas dos capitulos e desenvolvimento do conteúdo.

## 🤖 Tecnologias Utilizadas
IA Generativa ChatGPT para roteirização e revisão;
IA Generativa Midjourney para criação de ilustrações associadas ao tema;
Usei o PowerPoint para "montagem" do ebook e posteriormente converti em PDF

## 🧐 Processo de Criação
Busquei elaborar o Ebook com um tema bastante atual, pedi ao ChatGPT desenvolver a estrutura e os temas dos capitulos a partir do titulo que eu criei, "Desafios das Mudanças Climáticas no Brasil para 2025 e Como Minimizar seus
Efeitos". A partir daí, pedi ao ChatGPT para elaborar o conteudo com o tema de cada capitulo.
Com o Ebook montado, fui ao Midjourney e pedi para criar ilustrações informando o tema de cada capitulo. Colei cada ilustração ao capitulo de referencia.

## 🚀 Resultados
O resultado foi satisfatório. O tema foi abordado de forma relativamente profunda e bastante interessante.
